# MyKasir 
**A Modern Point of Sales (POS)**

Aplikasi Kasir cerdas yang dirancang untuk UMKM, mengedepankan efisiensi, desain modern (Royal Onyx Theme), dan pengalaman pengguna yang mulus. Proyek ini dibangun sebagai bagian dari pengembangan portofolio Android Development saya menggunakan teknologi terbaru di ekosistem Android.

## ✨ Fitur Utama
* **Smart Cashier System:** Scan barcode menggunakan kamera HP (ML Kit/Vision API) atau input manual.
* **Digital Receipt:** Bagikan struk pembelian secara instan via WhatsApp/Telegram tanpa printer thermal.
* **Smooth Navigation:** Transisi menu antar layar menggunakan `HorizontalPager` untuk pengalaman UX yang modern.
* **Micro-Interactions:** Feedback haptic dan animasi *bounce* pada tombol untuk sentuhan premium.
* **Local Database:** Manajemen data produk dan riwayat transaksi menggunakan Room Database.
* **Inventory Management:** Kelola stok barang langsung dari aplikasi.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Declarative UI)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Persistence:** Room Persistence Library
* **Dependency Injection:** Manual/ViewModelProvider
* **Animation:** Compose Animation (Swipe-to-Dismiss, AnimatedContent, PagerState)
